# Session log — 2026-09-11 — Fix CRAN Fedora install failure (enderecobr 0.6.1)

**Plan:** `quality_reports/plans/reflective-crunching-pixel.md` (approved 2026-09-11)
**Branch:** `fix/fedora-lR`

## Goal

CRAN flavors `r-devel-linux-x86_64-fedora-{clang,gcc}` fail to install 0.6.0
(`ld: cannot find -lR`). Ship 0.6.1 that installs on R builds without `libR.so`.

## Key context / decisions

- Cause: rextendr 0.5.0 scaffold runs `cargo run --bin document` at install → links a
  Rust binary against `-lR`; CRAN Fedora R has no `libR.so` (no `--enable-R-shlib`).
  Roger Bivand confirmed the same on issue #70.
- Not a `-L` problem: extendr-ffi `build.rs` already emits `rustc-link-search=$R_HOME/lib`.
- Fix = gate the step on `ROXYGEN_PKG` (mirrors rextendr dev template), flags aligned with
  the lib build to avoid a second full compile.
- Rejected: rextendr-dev `document.c` — needs `write__make_<pkg>_wrappers`, only on extendr
  git main, not in vendored extendr-api 0.9.0. Deleted the stray `src/rust/document.c`.
